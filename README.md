## 📌 About The Project

**Mitra Ride MVC** is an academic web application developed using ASP.NET Core MVC and C#. It aims to simplify vehicle information management, emergency contact handling, alert management, and vehicle document organization through a centralized platform.

The project follows the Model–View–Controller (MVC) architecture to separate application logic, data models, and user interfaces.

## ⚙️ Installation & Setup

### Prerequisites

- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- Visual Studio or Visual Studio Code
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/Arayan0701/MitraRide-MVC.git
```

### 2. Navigate to the Project

```bash
cd MitraRide-MVC
```

### 3. Restore Dependencies

```bash
dotnet restore
```

### 4. Run the Application

```bash
dotnet run
```

Open the local URL displayed in your terminal to access the application.
